Build your own 2nd Brain.

You've heard the buzz. Here's how to build one: a folder of your notes that your AI reads every chat, so it works the way you do. Free, about 45 minutes.

Obsidian + Claude or ChatGPT
Build mine 
You are my setup guide. Walk me through building a "2nd Brain": an Obsidian vault of my notes that you read at the start of every chat, synced through Google Drive so it works from my phone too. This follows Cole Stepanik's guide at https://colestepanik.vercel.app/brain.html. It takes about 45 minutes.

HOW TO RUN THIS
- First ask whether I'm on Windows or a Mac. From then on, give only the instructions for my computer.
- Give me one step at a time, then wait until I say it's done or ask a question.
- Assume I've never opened Obsidian. Use plain words and exact menu names. Menu names change as apps update, so if one doesn't match what I see, help me find the closest option.
- Start each reply with where we are, like "Phase 1, step 3 of 5".
- If something goes wrong, use the TROUBLESHOOTING section at the end.

WHAT I NEED
- A Claude plan with memory, skills, and connectors (these usually need a paid plan; I can check under Settings).
- Obsidian, free from obsidian.md.
- A Google account (any free Gmail).
- About 45 minutes.

FOUR WORDS I'LL SEE (explain them briefly at the start)
- Vault: a folder of plain text notes that any app can open.
- Skill: saved instructions Claude loads by name. Mine will be /brain.
- Connector: lets Claude read and write my Google Drive files.
- Mirror vs Stream: Google Drive's two modes. Obsidian needs Mirror, a real copy on my computer.

STARTER KIT (tell me to download these first)
- Vault template: https://colestepanik.vercel.app/kit/2nd-brain-vault-template.zip
- /brain skill: https://colestepanik.vercel.app/kit/brain-skill.zip
- Interview questions: https://colestepanik.vercel.app/kit/interview-questions.md

PHASE 1: SET UP THE FOUNDATION (about 15 minutes)
1. Install Obsidian (https://obsidian.md/download). Download the vault template and unzip it where it will live for good. Documents is best (Windows: C:\Users\your-name\Documents\2nd Brain, Mac: ~/Documents/2nd Brain). Never in Downloads. In Obsidian, choose "Open folder as vault" and pick that 2nd Brain folder. From scratch instead: "Create new vault", name it 2nd Brain, save it in Documents.
2. Install Google Drive for desktop (https://www.google.com/drive/download/) and sign in. This is the foundation: the vault lives on my computer and in Drive, so you can reach it from anywhere. Set it to Mirror files: Windows, the Drive icon in the system tray by the clock (maybe under the up arrow); Mac, the Drive icon in the menu bar. Then the gear, Preferences, Google Drive, Mirror files. Still in Preferences, open My Computer (Windows) or My Mac, click Add folder, pick the 2nd Brain folder, choose Sync with Google Drive, click Done, then Save.
3. Check that it synced. Windows: File Explorer, Documents, the folder shows a small Drive icon. Mac: Finder, Documents, maybe a sync badge. The real check: drive.google.com, Computers, then my computer. 2nd Brain should be there with all its folders.
4. In Obsidian, click the vault name at the bottom left, then Manage vaults. Open the folder with 00 Core directly inside it, not the folder above. Remove extra entries with Remove from list (this doesn't delete files).
Done when: 2nd Brain shows under Computers on drive.google.com, and Obsidian lists exactly one 2nd Brain vault.

PHASE 2: FILL IT WITH HOW I WORK (about 20 minutes)
5. Check the folders exist (the template has them): 00 Core, 01 Areas, 02 People, 02 Companies, 03 Projects, 05 Log, 06 Archive, _interview. If not, right-click the left sidebar and choose New folder for each.
6. Interview me, right here in this chat. Ask one question at a time and wait for my answer. If an answer is vague, ask one follow-up. Keep it to about 25 questions. If I paste the interview questions file, use it. Suggest I use voice dictation. Cover:
   a. What I'm working on right now, ranked by priority
   b. A real day when two things collided, and what I did first
   c. Rules I always or never break
   d. How I want you to talk to me (length, tone, how hard to push back)
   e. The people who matter in my work and what each one is to me
   f. The tools I use and what each one is for
   g. What a good week and a wasted week look like
   When we're done, write four markdown files, each in its own code block with the file name on top:
   - Operating Manual.md: my priorities and decision rules, in my own words
   - Identity.md: who you are to me and how you should talk to me
   - Tool Roles.md: what each tool is for
   - interview-[today's date].md: the full questions and answers, word for word
7. Save the files. In Obsidian, right-click 00 Core, choose New note, name it Operating Manual, and paste. Same for Identity and Tool Roles (the template has empty versions to paste over). The transcript goes in _interview.
8. Seed a few notes: one short note per main part of my life in 01 Areas (a class, a job, a club), one per key person in 02 People, one per organization in 02 Companies. Two lines each is plenty.
Done when: 00 Core has three notes with my real answers, and the transcript is in _interview. Drive syncs them on its own.

PHASE 3: TEACH CLAUDE TO USE IT (about 5 minutes)
9. Turn on memory: Settings, Memory section, turn on generating memory from chats.
10. Add the /brain skill: Settings, Capabilities, Skills, upload brain-skill.zip. No editing needed. If Skills is missing, turn on code execution and file creation on the same page first.
11. In Settings, Profile, paste this into personal preferences: "Apply /brain at the start of every chat. Keep a dated daily log in the vault."
Done when: typing /brain in a new chat is recognized. It may say it can't find the vault yet. That's expected; the next phase connects it.

PHASE 4: CONNECT CLAUDE AND TEST (about 10 minutes)
12. Settings, Connectors, Google Drive, Connect, using the same Google account as step 2.
13. Read test: I ask "Find my 2nd Brain folder in Google Drive and list what's in it."
14. Write test: I ask you to create Sync Test.md in my 2nd Brain folder that says "hello from my AI". After a minute it should appear in Obsidian on its own.
15. Round trip: I add a line to Sync Test in Obsidian, wait a minute, and ask you to read it back.
16. Point /brain at Drive: "Update my /brain skill to use my Google Drive 2nd Brain folder by default. Add its folder ID, and keep the safety rules: plain markdown, edit in place, one log file per date." Then I click to save the updated skill card.
17. The real test: in the Claude app on my phone, a new chat, ask "What did I do today?"
Done when: my phone answers from the vault. I can delete Sync Test whenever I like.

TROUBLESHOOTING
- Two 2nd Brain vaults in Obsidian: I opened the folder above the vault or a copy. In Manage vaults, keep the one with 00 Core directly inside and Remove from list the rest.
- Obsidian opens the old location: I moved the folder. Open folder as vault on the new location, remove the old entry, and re-add the new location in Drive's Preferences.
- The test note never shows up: Drive sync is paused or catching up. Click the Drive icon, resume if paused, wait for up to date. Check drive.google.com first; clicking the folder in Obsidian refreshes it.

AT THE END
Tell me: the more I use it, the better it gets. Keep notes in my own words and correct you when you're wrong; corrections become rules.

Set up the foundation

  1. 01Install Obsidian and pick where your vault lives

    All you'll need to download

    ObsidianFree notes app, obsidian.md Google Drive for desktopFree, sign in with Google

    Download both now and install Obsidian first; Google Drive is the very next step.

    Don't put it in Downloads. Windows can clean that folder out automatically.It's easy to delete by accident when you tidy up.

  2. 02Install Google Drive and mirror your vault

    This is the foundation: your vault lives on your computer and in Google Drive, so your AI can reach it from anywhere, even your phone.

    Install Google Drive for desktop (the blue card above) and sign in with your Google account.

    Click the Drive icon in the system tray, at the bottom right by the clock (it may be hidden under the little up arrow). Click the gear, then Preferences, then Google Drive, and choose Mirror files.

    Click the Drive icon in the menu bar at the top right of your screen. Click the gear, then Preferences, then Google Drive, and choose Mirror files.

    Still in Preferences, open My ComputerMy Mac, click Add folder, pick your 2nd Brain folder, and choose Sync with Google Drive. Click Done, then Save.

  3. 03Check that it synced

    Open File Explorer and go to Documents. Your 2nd Brain folder should show a small Google Drive icon.

    Open Finder and go to Documents. Your 2nd Brain folder may show a small sync badge.

    The real check: open drive.google.com, click Computers in the left menu, then your computer. 2nd Brain should be there with all its folders.

  4. 04Make sure Obsidian opens the right folder

    In Obsidian, click your vault name at the bottom left, then Manage vaults. Look at the path under each vault. Open the folder that has 00 Core directly inside it, not the folder above it. Remove any extra entries with Remove from list (this doesn't delete files).

You're done when 2nd Brain shows under Computers on drive.google.com, and Obsidian lists exactly one 2nd Brain vault.

If something goes wrong

The three things most likely to trip you up, and how to fix each one. Menu names also change as these apps update; if one doesn't match, look for the closest option or ask your AI where that setting lives today.

Two "2nd Brain" vaults show up in Obsidian

You probably opened the folder above your vault, or a copy of it. In Manage vaults, check the path under each one. Keep the one that has 00 Core directly inside it and click Remove from list on the rest. Removing doesn't delete any files.

Obsidian still opens the old location

If you moved the folder after creating the vault, Obsidian remembers the old path. Choose Open folder as vault, pick the folder in its new location, then remove the old entry from Manage vaults. If you'd already added the old folder to Google Drive, re-add the new location in Drive's Preferences too.

The test note never shows up

Drive sync is usually paused or still catching up. Click the Drive icon in the system traymenu bar: if it says paused, resume it, and wait until it says it's up to date. Check drive.google.com first. If the note is there, Obsidian shows it within a few seconds; clicking the folder refreshes it.
