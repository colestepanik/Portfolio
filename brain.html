Build your own 2nd Brain.

You've heard the buzz. Here's how to build one: a folder of your notes that your AI reads every chat, so it works the way you do. Free, about 45 minutes.

Obsidian + Claude or ChatGPT
Build mine 
You are my setup guide. Walk me through building a "2nd Brain": an Obsidian vault of my notes that you read at the start of every chat, synced through Google Drive so it works from my phone too. This follows Cole Stepanik's guide at https://colestepanik.vercel.app/brain.html. It takes about 45 minutes.

HOW TO RUN THIS
- First ask whether I'm on Windows or a Mac. From then on, give only the instructions for my computer.
- Give me one step at a time, then wait until I say it's done or ask a question.
- Assume I've never opened Obsidian. Use plain words and exact menu names. Menu names change as apps update, so if one doesn't match what I see, help me find the closest option.
- Start each reply with where we are, like "Phase 1, step 3 of 5".
- If something goes wrong, use the TROUBLESHOOTING section at the end.

WHAT I NEED
- A Claude plan with memory, skills, and connectors (these usually need a paid plan; I can check under Settings).
- Obsidian, free from obsidian.md.
- A Google account (any free Gmail).
- About 45 minutes.

FOUR WORDS I'LL SEE (explain them briefly at the start)
- Vault: a folder of plain text notes that any app can open.
- Skill: saved instructions Claude loads by name. Mine will be /brain.
- Connector: lets Claude read and write my Google Drive files.
- Mirror vs Stream: Google Drive's two modes. Obsidian needs Mirror, a real copy on my computer.

NOTHING TO DOWNLOAD BUT TWO APPS
There are no templates to unzip. Once Google Drive is connected, you build the vault and my /brain skill yourself, right in this chat.

PHASE 1: SET UP THE FOUNDATION (about 15 minutes)
1. Install Obsidian (https://obsidian.md/download). Open it and click "Create new vault". Name it 2nd Brain, or whatever I like. For the location, make a new folder where it will live for good, like Documents (Windows: C:\Users\your-name\Documents\2nd Brain, Mac: ~/Documents/2nd Brain), not Downloads. It starts empty.
2. Install Google Drive for desktop (https://www.google.com/drive/download/) and sign in. This is the foundation: the vault lives on my computer and in Drive, so you can reach it from anywhere. Set it to Mirror files: Windows, the Drive icon in the system tray by the clock (maybe under the up arrow); Mac, the Drive icon in the menu bar. Then the gear icon at the top right, Preferences, Google Drive, Mirror files. When it asks for a folder, I pick the 2nd Brain folder, then let Drive restart. That's all: the vault now syncs under My Drive. There's no Add folder step (Drive would say the folder is already connected).
3. Check that it synced. Windows: File Explorer, Documents, the folder shows a small Drive icon. Mac: Finder, Documents, maybe a sync badge. The real check: drive.google.com, My Drive. 2nd Brain should be there.
4. In Obsidian, click the vault name at the bottom left, then Manage vaults. The path should end in 2nd Brain, not the folder above it. Remove extra entries with Remove from list (this doesn't delete files).
Done when: 2nd Brain shows under My Drive on drive.google.com, and Obsidian lists exactly one 2nd Brain vault.

PHASE 2: CONNECT CLAUDE (about 5 minutes)
5. Turn on memory: Settings, Memory section, turn on generating memory from chats.
6. Settings, Connectors, Google Drive, Connect, using the same Google account as step 2. Then make sure Google Drive is turned on for this chat.
7. Find my 2nd Brain folder in Google Drive and tell me what's in it. It should be empty. If you can't find it, tell me to attach the folder to this chat: the + in the message box, add from Google Drive, pick 2nd Brain.
Done when: you can see my empty 2nd Brain folder.

PHASE 3: BUILD IT (about 25 minutes, you do the work)
8. Set up the vault. In the 2nd Brain folder, create these folders, each with a short README.md that says what goes in it: 00 Core, 01 Areas, 02 People, 02 Companies, 03 Projects, 05 Log, 06 Archive, _interview. Work in that folder only, plain markdown.
9. Interview me so you can work the way I do. List all your questions at once, numbered, about 25 of them, so I can answer them all in one reply. Suggest I use voice dictation. When I've answered, check you have everything you need and ask only the follow-ups you need. Cover:
   a. What I'm working on right now, ranked by priority
   b. A real day when two things collided, and what I did first
   c. Rules I always or never break
   d. How I want you to talk to me (length, tone, how hard to push back)
   e. The people who matter in my work and what each one is to me
   f. The tools I use and what each one is for
   g. What a good week and a wasted week look like
10. Write my vault into the folder:
   - 00 Core/Operating Manual.md: my priorities and decision rules, in my own words
   - 00 Core/Identity.md: who you are to me and how you should talk to me
   - 00 Core/Tool Roles.md: what each tool is for
   - _interview/interview-[today's date].md: the full questions and answers, word for word
   - One short note for each area of my life in 01 Areas, each key person in 02 People, and each organization in 02 Companies. Two lines each.
11. Make my /brain skill. Create a skill called "brain" that, at the start of every chat, finds this 2nd Brain folder in Google Drive (include its folder ID so it never has to search), reads 00 Core first and then only the notes the task touches, makes calls the way my Operating Manual says, and writes back what it learns: edits notes in place, keeps one dated log file per day in 05 Log, plain markdown only. Show me the skill card so I can save it. If I don't see one, I turn on code execution and file creation under Settings, Capabilities, and you show it again. Then, so you use it every chat, I paste this into Settings, Profile, personal preferences: "Apply /brain at the start of every chat. Keep a dated daily log in the vault."
12. I open Obsidian. Within a minute or two the folders and notes appear as Drive syncs. I read the three 00 Core notes and tell you anything to fix, and you edit them; I shouldn't have to edit anything by hand.
Done when: 00 Core in Obsidian has my three notes, and typing /brain in a new chat brings up the skill.

PHASE 4: TEST (about 5 minutes)
13. Round trip: I add a line to my Operating Manual in Obsidian, wait a minute, and ask you to read it back. If you see my new line, the loop works both ways.
14. The real test: in the Claude app on my phone, a new chat, ask "What did I do today?" Explain that the phone app can't open Obsidian; it reads the vault's copy in Google Drive, which is why we mirrored it.
Done when: my phone answers from the vault.

TROUBLESHOOTING
- Two 2nd Brain vaults in Obsidian: I opened the folder above the vault or a copy. In Manage vaults, keep the one with 00 Core directly inside and Remove from list the rest.
- Obsidian opens the old location: I moved the folder. Open folder as vault on the new location, remove the old entry, and pick the new location in Drive's Preferences.
- Notes from you never show up in Obsidian: Drive sync is paused or catching up. Click the Drive icon, resume if paused, wait for up to date. Check drive.google.com first; clicking the folder in Obsidian refreshes it.

AT THE END
Tell me: the more I use it, the better it gets. Keep notes in my own words and correct you when you're wrong; corrections become rules.

Set up the foundation

  1. 01Install Obsidian and create your vault

    All you'll need to download

    ObsidianFree notes app, obsidian.md Google Drive for desktopFree, sign in with Google

    Don't put it in Downloads. Windows can clean that folder out automatically.It's easy to delete by accident when you tidy up.

  2. 02Install Google Drive and mirror your vault

    This is the foundation: your vault lives on your computer and in Google Drive, so your AI can reach it from anywhere, even your phone.

    Install Google Drive for desktop (the blue card above) and sign in with your Google account.

    Click the Drive icon in the system tray, at the bottom right by the clock (it may be hidden under the little up arrow).

    Click the Drive icon in the menu bar at the top right of your screen.

    Click the gear icon at the top right, then Preferences, then Google Drive, and choose Mirror files. When it asks for a folder, pick your 2nd Brain folder. Drive asks to restart; let it.

    That's it: your vault now syncs under My Drive. You don't need Add folder; if you try it, Drive tells you the folder is already connected.

  3. 03Check that it synced

    Open File Explorer and go to Documents. Your 2nd Brain folder should show a small Google Drive icon.

    Open Finder and go to Documents. Your 2nd Brain folder may show a small sync badge.

    The real check: open drive.google.com and click My Drive in the left menu. 2nd Brain should be there.

  4. 04Make sure Obsidian opens the right folder

    In Obsidian, click your vault name at the bottom left, then Manage vaults. Look at the path under each vault: it should end in 2nd Brain, not the folder above it. Remove any extra entries with Remove from list (this doesn't delete files).

You're done when 2nd Brain shows under My Drive on drive.google.com, and Obsidian lists exactly one 2nd Brain vault.

If something goes wrong

The three things most likely to trip you up, and how to fix each one. Menu names also change as these apps update; if one doesn't match, look for the closest option or ask your AI where that setting lives today.

Two "2nd Brain" vaults show up in Obsidian

You probably opened the folder above your vault, or a copy of it. In Manage vaults, check the path under each one. Keep the one that has 00 Core directly inside it and click Remove from list on the rest. Removing doesn't delete any files.

Obsidian still opens the old location

If you moved the folder after creating the vault, Obsidian remembers the old path. Choose Open folder as vault, pick the folder in its new location, then remove the old entry from Manage vaults. If you'd already picked the old folder in Google Drive, pick the new one in Drive's Preferences too.

Notes from your AI never show up

Drive sync is usually paused or still catching up. Click the Drive icon in the system traymenu bar: if it says paused, resume it, and wait until it says it's up to date. Check drive.google.com first. If the notes are there, Obsidian shows them within a few seconds; clicking the folder refreshes it.
